# Reproduction arm — the authors' own code

Runs executed with `train_and_eval_pytorch.py` from [MedMNIST/experiments](https://github.com/MedMNIST/experiments), unmodified. This is **not** the replication arm; for our independent reimplementation see `comparison.md`, generated by `src.aggregate`.

`--resize` upsamples the 28-pixel data to 224, so these compare against the paper's **224** column of Table 3.

Tolerance: |ΔAUC| ≤ 0.02, |ΔACC| ≤ 0.03. Delta = ours − paper. **Single seed per config — no variance is claimed.**
